Este mapa muestra las estaciones consideradas para el análisis. Al hacer clic sobre cada estación, se muestra su nombre, variable asociada, organismo encargado, con su respectiva sigla; y comuna. La delimitación de la cuenca Río Cautín en Cajón fue obtenida a partir del dataset CAMELS-CL (Alvarez-Garreton et al., 2018).

Variables

Todas las variables tienen una frecuencia regular, de seis horas entre pasos. La variable objetivo, la que se busca predecir es el caudal instantáneo en la estación Río Cautín en Cajón para un paso i dado. Las información de las otras tres estaciones sirvió como predictora, y, para los tres modelos mencionados, se usa la información de los 28 pasos anteriores, es decir, desde i-28 hasta i-1, para obtener el valor objetivo.
