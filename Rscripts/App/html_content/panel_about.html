Generalidades

Esta plataforma web permite visualizar los resultados obtenidos en la investigación para subintervalos del intervalo de prueba, con una resolución diaria. Este está comprendido entre el 13-10-2013, 12:00:00 y el 28-07-2014, 18:00:00; en zona horaria UTC. La filtración se puede realizar seleccionando los modelos a examinar y/o el rango de fechas de interés. En los gráficos, por simplicidad se usan las siglas:

  • LSTM para el modelo homónimo,
  • Obs para la serie observada,
  • RF para Random Forest, y
  • XGB para XGBoost.

Finalmente, se puede descargar un reporte en formato .pdf con el contenido de las pestañas Series y Métricas; y, además, una tabla con todos los valores obtenidos dentro del rango de fechas seleccionado.
